# Repo Tracking

这个目录记录当前仓库的**工作进展跟踪**（session handoff / 日志），
不是运行时 trajectory / action 的 trace（那些在 `action_logs/`）。

## 文件

- `overview.md`: 长期背景、目标、里程碑
- `current.md`: 当前快照（下一会话优先读）
- `decisions.md`: 重要决策与理由
- `daily/YYYY-MM-DD.md`: 每天一篇日志

## 开始工作

1. 先读 `current.md`
2. 需要更多背景时再读 `overview.md`
3. 需要近期历史时再看最近 1–3 篇 daily

## 结束工作

1. 追加今天的 daily
2. 更新 `current.md`
3. 有实质决策时写入 `decisions.md`
4. 目标 / 阶段变化时更新 `overview.md`
